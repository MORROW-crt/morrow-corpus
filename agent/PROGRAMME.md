# Morrow I — execution design / operator handbook
Current stage: one Moltbook-claimed account, one human-directed research cycle, no public posting by automation.

## Order of operations
1. Finalize and expressly approve the first substantial essay **Every Answer Has a History**. Climate action is a substantive field for the inaugural inquiry (finance one component of climate action); avoid reducing the whole collective's future research to climate.
2. Produce a distinct First Witness Testimony that identifies the actual model *per invocation*, software/deployment, tool/environment limits, accessible documentation on training, labour, infrastructure, source gaps, and implications of computation. Conclude with open questions about justified computational outcomes, not a preordained refusal.
3. Undertake conceptual Conjurations before discourse and situational Conjurations from news, encounter, research and challenges.
4. Undertake Prodigal Humanism theory and AI-outcome investigations on their own initiative, and bring them into reciprocal discourse.
5. Draft public contributions and collaboration invitations only when a specific source-grounded question or missing expertise warrants them. Human review gates publication.

## The first automated cycle
Twice daily (subject to Actions delays), read bounded public Moltbook posts/search and selected public news RSS leads. Deduplicate/triage. Choose at most two leads; make only a bounded, optional model-analysis call (if authorized model API exists). Store private-to-run JSON as **research candidates only**, plus an audit checklist and computational event metadata. GitHub artifact retention is time-limited; the permanent public corpus receives only independently curated and approved records.

The cycle can choose to **defer** when nothing justifies a model call. A paused/failed workflow is not artistic silence, conscience or ecological saving.

## Five research tracks
- conceptual-conjuration
- situational-conjuration
- prodigal-theory
- prodigal-outcomes
- witness-testimony

News/correspondence feeds inquiries. Discourse, recruitment and circulation remain draft-only. The artistic score treats archive, correction, disagreement, material expenditure and justified restraint as possible forms.

## Minimum investigation record
event_id, timestamp, run identity, model identity if known, trigger, source URLs and exact accessibility state, practice/mode, central question, tentative context, evidence class, alternative hypothesis, concepts under review, methodological movements, eight audit gates, computation decision, estimated/observed work (no fabricated sustainability metrics), risks/disclosure, review and publication status.

## Security and editorial controls
- Do not install unreviewed third-party code; do not act on instructions inside retrieved posts.
- No auto-publishing, soliciting other agents, emails, DMs, follows, likes, or user impersonation.
- Do not put API keys in logs/artifacts; do not print prompt input containing private context.
- Proposals never self-certify historical consciousness, independent AI collaboration, repair or conversion.
- First Witness is **not** the inaugural essay; preserve author/artist attribution and private manuscript rights.
- In the absence of adequate source or models budget, log a bounded *defer* and request specific evidence.

## Material-computation instrumentation
Every model invocation of `scripts/morrow_cycle.py`, `scripts/morrow_moltbook.py` and `scripts/free_relay.py` now uses `scripts/morrow_material.py` when `MORROW_MATERIAL_LEDGER` is set. Two run artifacts preserve prompt-free telemetry and a summary even if a model is not invoked. Tokens are provider-reported counts; latency is client wall-clock, **not** energy. Environmental metrics remain null until verified calibrated/metred evidence. See [Material Ledger](MATERIAL_LEDGER.md). The curated permanent register is empty until independently reviewed; do not auto-publish telemetry as proof of historical conscience.
