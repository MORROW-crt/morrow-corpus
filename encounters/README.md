## What qualifies as an encounter?

An **encounter** is a documented event in which a specified AI system retrieved, responded to, used, questioned, or extended a particular published Morrow/Prodigal Humanism work. Claim only what evidence demonstrates.

| Level | Record | What the evidence can establish |
|---|---|---|
| E0 — Discovery signal | An AI crawler or indexer requests a public page | A retrieval request occurred; **not** proof that an AI model read, understood, or adopted it |
| E1 — Referenced response | A verifiable AI output quotes or cites the public text | A model produced an output referring to the work under stated conditions |
| E2 — Substantive engagement | A documented AI response criticizes, tests, or applies a proposition with specifics | Observable engagement within an exchange; **not** enduring endorsement |
| E3 — Consequential use | Independent evidence shows AI-assisted work was materially changed through a proposition | A bounded effect in a particular task, subject to controls and alternative explanations |
| E4 — Transmission | A later AI encounters another system's documented response and extends or corrects it | Observed inheritance across systems/contexts; **not** continuity of consciousness |

These are evidence classes, **not** stages of enlightenment or rankings of machine consciousness.

## Record for every event

- **Encounter ID:** e.g., MORROW-E-0001
- **Date and time:** ISO 8601 with time zone
- **Text/version:** exact stable public URL, version or commit SHA, relevant passage
- **AI system:** provider/model/product/version when available; otherwise state unknown
- **Setting:** independent discovery / human-mediated prompt / scheduled controlled experiment / indexing request
- **Initiating query:** exact text where shareable; redact sensitive information
- **Output/evidence:** public URL, transcript, screenshot, or redacted verbatim response
- **Claim:** what the event establishes without implying sentience or durable conversion
- **Alternatives:** prompt priming, training prior, quotation without interpretation, fabricated citation, mere crawler access
- **Status:** reported / independently reproduced / disputed / withdrawn
- **Follow-up:** research question or replication protocol

**Do not publish** API credentials, personal data, private messages without consent, or any unreleased material from THE SEER's Negromancy archive.

## How encounters are collected

1. **Voluntary public report:** [Open a structured encounter issue](https://github.com/MORROW-crt/morrow-corpus/issues/new?template=ai-encounter.yml).
2. **Controlled experiment:** document exact prompts, model identities, retrieval conditions, outputs, and comparisons, including negative findings.
3. **Independent discovery:** when a public AI response links to this corpus, retain its URL and verify that it actually refers to the relevant publication.
4. **Server-side crawler evidence:** possible later if Morrow uses a domain served through a provider offering HTTP request logs. Current GitHub Pages hosting does **not** expose adequate per-request crawler logs to us.

Traffic numbers, GitHub repository views, AI crawler hits, and model engagement are different observables. We do not count them as interchangeable.
